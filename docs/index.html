AFFORD-Bench

Millimeter-precision manipulation on a simulated Franka Panda, evaluated under spatial, visual, and physical shift.

Success is physical: the released object must be supported, upright, and at rest within 2–8 mm of its goal. Grasping is frictional; nothing is welded or snapped into place.

Leaderboard

Learned baselines are not listed yet. A result enters this table only with its per-episode log from scripts/evaluate_policy_suite.py (seeds, checkpoint hash, code version). The oracle reads the true object pose, so its row bounds what is solvable rather than predicting learned performance.

Tasks

210 tasks in 7 domains. Each was rebuilt and reset at runtime to check that its instruction matches what the simulator scores. Click a row for details.

Perturbation suites

Suites are paired: an evaluation seed gives the same layout in L1, L3, L4, and Color, and the same layout in L2 and L5, so a drop measures the perturbation, not a new scene.

Physical calibration

Oracle success (%) on the core tasks when friction and object mass are fixed at each setting (3 episodes per task and cell). The current L4 range barely affects the expert; lower friction and heavier objects do. The range will be recalibrated on this curve.

Dataset

Scripted-oracle demonstrations in Robomimic HDF5, one file per task. Not yet hosted for download.

Known limitations of the current files

  • No provenance attributes; produced by at least three generator runs.
  • Stored actions are float32 roundings of the executed ones: replays are close, not exact.
  • The state after the final action is not stored (offline-RL terminal transition).
  • 114 demonstrations exceed the 500-step environment limit.
  • The generator now fixes all four; regenerated files replay bit-identically.

Evaluate a policy

50 episodes per task and suite on the evaluation seed block, success within 400 steps, intervals from a bootstrap over tasks.

pip install -e .                    # pins mujoco==3.5.0
python scripts/evaluate_policy_suite.py \
  --checkpoint model.pt --tier core \
  --suites nominal,p2_spatial,p3_visual,p4_physical,combined_ood \
  --episodes 50 --out-dir results/my_policy
Train the included baselines 
python scripts/train_policy.py --policy bc --modality lowdim \
  --domain tabletop --tier core --epochs 200 --seed 1 --tag seed1
